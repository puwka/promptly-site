Privacy Policy

Last updated: September 19, 2026

Promptly (“we”, “the extension”) is an AI Chrome extension that helps you ask questions about selected text, images, and web pages.

What we collect

Depending on how you use Promptly, we may process:

  • Installation id — a random local id used for Free/Pro usage limits.
  • Chrome profile email (optional) — to restore a paid subscription after reinstall and sync settings / history / custom actions. Not used for advertising.
  • AI request payload — text, page excerpt, or image you choose to send, transmitted to our backend to generate an answer.
  • AI request metadata — model name, context type, usage counts, timestamps. Analytics do not store full prompts, full page HTML, or images.
  • Usage counters — Free daily limits and Pro weekly token limits.
  • Synced workspace data — when a Chrome profile email is available, settings, custom actions, and conversations may sync so they survive reinstall.
  • Billing identifiers — Stripe customer / subscription ids for Promptly Pro.
  • Product analytics — aggregate events such as install or paywall viewed (no prompt text, page content, cookies, or API keys).

How AI requests work

Selected text / page excerpt / image is sent to our backend (Supabase Edge Function), which calls NeuroAPI. Provider keys stay on the server and never ship inside the extension package.

Payments

Paid plans are processed by Stripe. Card details are entered on Stripe Checkout / Customer Portal and are not stored by Promptly.

Cookies & tracking

The extension does not use third-party advertising cookies. Analytics are first-party product events stored in our Supabase project.

Data sharing

We do not sell personal data. Subprocessors:

  • Supabase — database, Edge Functions, optional sync storage
  • NeuroAPI — AI model inference
  • Stripe — subscription payments

Your choices

  • Turn off or clear chat history in Settings.
  • Manage or cancel Pro via Settings → Manage subscription.
  • Uninstall the extension to stop local processing and new sync.
