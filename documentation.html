Installation

  1. Open the Promptly listing on the Chrome Web Store.
  2. After install, Promptly opens this site. Sign in with Google or email. If you are already signed in, the extension links automatically.
  3. Choose Upgrade to Pro in the extension to open Pricing. Get Pro starts RollyPay checkout for that browser install.
  4. Click Add to Chrome and confirm the permissions.
  5. Pin Promptly from the extensions menu for quick access.
  6. Open the side panel from the Promptly icon or the page context menu.

Main features

  • AI chat — converse in Chrome’s side panel while browsing.
  • Text — ask about or transform selected text on the page.
  • Images — analyze images from the current context.
  • PDF & files — work with PDFs and files in the browser.
  • Google Docs — use Promptly while editing Docs.
  • AI Search — search with AI assistance.
  • Memory — keep useful context across related asks.
  • Models — choose among supported AI model families.

Account

Sign in at /login. Promptly links the signed-in email to this browser’s installation id. /account shows the email, Free or Pro, subscription status, the next billing date, and Manage subscription.

Chat transcripts, document text, page contents, and images are not saved in the account. Pro status comes from the confirmed RollyPay payment, not from a flag stored only in Chrome.

Troubleshooting

  • Refresh the tab after installing or updating Promptly.
  • Confirm you are online — AI requests need network access.
  • If a model fails, try another supported model family.
  • For image or file issues, re-open the source and try again.
  • If payment fails or billing looks wrong, message @promptllyai on Telegram, X, Instagram, or Threads — include your purchase email and approximate payment time.
  • Still stuck? Use the form on Support.
